# munawira.github.io

Personal research site for Munawira Kotyad — GPU microarchitecture, instruction
issue, warp scheduling.

Built with Jekyll and served by GitHub Pages. Excluded from the build (see
`_config.yml`), so this file is not published.

- Pages: `index.md`, `research.md`, `publications.md`, `writing.md`, `cv.md`
- Posts: `_posts/YYYY-MM-DD-slug.md`
- Styles: `assets/css/main.css`

See `SETUP.md` for how to add posts and what to edit.
